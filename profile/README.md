# Elysium
    This is the official github organization for Elysium
    Elysium is a tool that allows for developers to run Lua in real time inside of Minecraft version 1.8.9 it offers a rich user interface that is easy to use.
    This project has been discontinued, although it is mostly done and does what it is supposed to do to a full extent.

## Release
    In order to use just download the release from here:
    https://github.com/ElysiumRecode/Caelum/releases/tag/release
## Scripts
    All you have to do is run the executable inside of a folder, you can write your own scripts or use one we already made here:
    https://github.com/ElysiumRecode/Equity
